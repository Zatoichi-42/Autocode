# Escape Hatches Audit — Everything That Will Fail

There are no edge cases. Every failure listed here WILL happen.

## CRITICAL: Hook Exit Code Bug (Affects ALL Our Hooks)

**The bug**: Our hooks use `exit 1` to block actions. In Claude Code,
exit code 1 is a NON-BLOCKING error. The action PROCEEDS and a warning
is logged that nobody sees. Only `exit 2` actually blocks.

**Impact**: Every security hook we wrote (pre-tool-security.sh,
pre-write-guard.sh) provides FALSE security. They look like they're
blocking but they aren't.

**Fix**: All hooks must use `exit 2` for blocking, and must wrap
everything in a trap so that ANY unexpected error also exits 2 (fail
closed, not fail open).

**Status**: FIXED in hook rewrite below.

## CRITICAL: Hooks Only Fire on Matching Tools

**The bug**: PreToolUse:Write hooks only fire when Claude uses the
Write tool. If Claude writes a secret via `echo "key=abc" > file.txt`
using the Bash tool, the Write hook never sees it.

**Impact**: Claude can bypass file protection by using Bash instead of
Write/Edit. This WILL happen because Claude naturally uses Bash for
file operations.

**Fix**: Add a PostToolUse hook on Bash that scans changed files.
Also add a pre-commit git hook as final safety net.

**Status**: FIXED in hook rewrite below.

## CRITICAL: Stop Hook Infinite Loop

**The bug**: Stop hooks that output text cause Claude to process that
text, which triggers another Stop, which fires the hook again. Infinite
loop until context exhaustion.

**Fix**: Check `stop_hook_active` field in input JSON. Exit immediately
if true.

**Status**: FIXED in hook rewrite below.

## HIGH: jq Not Installed

**The bug**: Every hook depends on jq for JSON parsing. If jq isn't
installed, hooks silently fail (exit 1 = non-blocking = action proceeds).

**Fix**: Every hook checks for jq first. If missing, fail closed (exit 2)
with clear error message.

**Status**: FIXED in hook rewrite below.

## HIGH: Hook Script Not Executable

**The bug**: chmod +x not run after git clone or file creation. Hook
silently doesn't execute. All protections gone.

**Fix**: Bootstrap checks and fixes permissions. SessionStart hook
verifies sibling hooks are executable.

**Status**: FIXED in bootstrap command and session-start hook.

## HIGH: Stale JOURNAL.md After Hard Kill

**The bug**: If the process is SIGKILL'd (kill -9), the Stop hook
never fires. JOURNAL.md is stale. Next session has wrong context.

**Impact**: Conductor sends stale context to next session. Work gets
duplicated or conflicts.

**Fix**: Conductor validates journal timestamp. Warns in prompt if
stale (>1h). Already implemented.

## HIGH: Conductor Itself Crashes

**The bug**: The bash conductor can crash (disk full, OOM, SSH
disconnect, laptop sleep).

**Fix**: The conductor is designed to be re-entrant. Running
`conductor.sh --auto` again reads conductor-state.json and resumes.
No single run owns the state. Add to crontab as a watchdog:
`*/10 * * * * cd /path/to/project && bash scripts/conductor.sh --auto`
Cron restarts it if it dies. The conductor checks if another instance
is running via pidfile before spawning sessions.

**Status**: Pidfile check ADDED in conductor update.

## HIGH: Conductor Spawns Overlapping Sessions

**The bug**: If conductor.sh is run twice (cron + manual), two
sessions edit the same files simultaneously. Corruption.

**Fix**: Pidfile lock. Second instance exits immediately.

**Status**: FIXED in conductor update.

## MEDIUM: Claude Writes Bad Code That Passes Tests

**The bug**: Tests can be too weak. Claude writes code that technically
passes but is wrong (wrong algorithm, bad UX, security hole).

**Fix**: No automated fix for this. This is why the human exists.
The dashboard, walkthrough, and /check command surface the results
so the human can catch what tests can't. The code-reviewer subagent
catches some issues. The self-critic catches design-level flaws.
But ultimately, tests are the quality floor, not the ceiling.

**Mitigation**: Write better tests. The meta-ratchet will eventually
propose test improvements based on bugs that escaped.

## MEDIUM: Claude Modifies Tests to Make Them Pass

**The bug**: Despite CLAUDE.md rule, Claude will sometimes modify
test files anyway (~20% non-compliance on advisory rules).

**Fix**: PreToolUse hook on Write/Edit that checks if file path
matches test patterns. Exits 2 (blocking) if so during implementation.

**Status**: FIXED in hook rewrite below.

## MEDIUM: Dashboard/Walkthrough HTML Generation Fails

**The bug**: If the /dashboard or /walkthrough command produces
broken HTML, the human sees a blank page or errors.

**Fix**: These are convenience outputs, not critical infrastructure.
The plain-text /digest and /check commands still work. The conductor
status page is generated by bash (simpler, fewer failure modes).
If HTML generation fails, text reports remain the fallback.

## MEDIUM: Rate Limit Backoff Insufficient

**The bug**: 5-minute wait may not be enough. Rate limit window may
be longer than expected.

**Fix**: Exponential backoff. First wait 5min, second 10min, third
20min. After 3 rate limits: stop and wait for human.

**Status**: FIXED in conductor update.

## MEDIUM: Git State Corruption

**The bug**: Concurrent worktrees, interrupted commits, or force
operations can corrupt git state.

**Fix**: Hooks block force-push. Each session works on its own branch.
Recovery: `git fsck && git reflog` to find good state.

## LOW: OS Disk Full

**The bug**: Logs, transcripts, and report files accumulate.
Eventually disk fills.

**Fix**: SessionStart hook checks disk space. Conductor prunes logs
older than 7 days. Add to session-start.sh.

## LOW: Python/Node Not Installed

**The bug**: Test runner and build commands fail if runtime is missing.

**Fix**: Bootstrap /health command checks for required tools and reports
missing ones clearly. Conductor checks before spawning sessions.

## LOW: Network Down

**The bug**: Scout skill can't fetch changelog. Some MCP tools fail.

**Fix**: Scout checks network first. MCP failures are non-fatal.
All core functionality (tests, build, lint, git) works offline.
